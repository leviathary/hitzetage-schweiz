Was zeigt diese Anwendung?

Was ist ein Hitzetag?

Ein Tag, an dem die gemessene Höchsttemperatur mindestens 30 °C erreicht.

Was ist eine Tropennacht?

Eine Nacht, in der die Temperatur nicht unter 20 °C fällt, ausgewertet über das Tagesminimum.

Was ist ein Frosttag?

Ein Tag, an dem die gemessene Tiefsttemperatur unter 0 °C fällt.

Was ist ein Eistag?

Ein Tag, an dem auch die gemessene Höchsttemperatur unter 0 °C bleibt.

Was ist ein Sommertag?

Ein Tag, an dem die gemessene Höchsttemperatur mindestens 25 °C erreicht.

Was ist ein sehr heisser Tag?

Ein Tag, an dem die gemessene Höchsttemperatur mindestens 35 °C erreicht.

Was bedeutet längste Hitzewelle?

Die längste Folge aufeinanderfolgender Tage mit einer Höchsttemperatur von mindestens 30 °C.

Was bedeutet längste Frostperiode?

Die längste Folge aufeinanderfolgender Tage, an denen die Tiefsttemperatur unter 0 °C fällt.

Woher stammen die Daten?

Historische Messwerte und Stationsangaben stammen aus dem offiziellen Open-Data-Angebot von MeteoSwiss; Prognosen werden gesondert gekennzeichnet.
